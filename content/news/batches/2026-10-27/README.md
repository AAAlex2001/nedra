# Редакционная пачка: 200 материалов

Статьи находятся в `content/news/articles/`, обложки — в
`frontend/public/news/`, сведения об авторах фотографий и лицензиях —
в `content/news/covers.json`. Фотографии иллюстративные: они не обозначают
объекты института и не подтверждают выполнение им работ на этих площадках.
Атрибуция добавляется импортёром в конец каждой статьи.

`plan.json` содержит состав этой пачки. Следующий заказ расширен до 500
материалов; его отдельный план находится в `../2026-10-28-500/plan.json`.

Проверки:

- `quality-report.json`: формат, объём, SEO-поля, повторы внутри пачки,
  наличие обложек и лицензий.
- `existing-overlap.json`: сравнение текстов с прежними 1990 статьями.
- `perceptual-cover-check.json`: сравнение обложек между собой и со старой
  библиотекой.
- `final-covers.json`: результат визуального отбора иллюстраций.

Проверка сходства локальная и не заменяет внешнюю проверку уникальности.
Поисковые позиции и заявки не гарантируются.

После включения в основной план статьи с `published: true` и
`publish_on_import: true` публикуются существующим workflow при push в
`main` и успешном импорте. Дата новых материалов — фактическое время
импорта, без искусственного распределения по прошлым неделям. Даты уже
опубликованных материалов сохраняются.

Повторная проверка:

```sh
python scripts/news/review_batch.py
python scripts/news/validate.py
python -m unittest discover -s scripts/news -p 'test_*.py'
```
