# Пачка: 500 новых статей

Все 500 материалов записаны в `content/news/articles/` и включены в основной
`content/news/plan.json`. Это новая пачка сверх предыдущих 200 статей;
в основном плане теперь 2690 записей. У новых материалов установлены
`published: true` и `publish_on_import: true`.

500 обложек находятся в `frontend/public/news/`. Источники фотографий — Flickr,
авторы и лицензии сохранены в `content/news/covers.json`. Использованы снимки
с лицензиями CC BY, CC BY-SA, CC0 и Public Domain; сведения о кадрировании
и обработке также сохранены. Импортёр добавляет подпись к каждой статье.
Фотографии иллюстративные и не обозначают выполненные институтом проекты.

Проверки:

- `quality-report.json`: объём, структура, SEO-поля, повторы внутри пачки,
  файлы обложек, источники и лицензии.
- `existing-overlap.json`: сравнение 500 текстов с прежними 2190 статьями.
- `integration-check.json`: HTML, ссылки, метаданные и сборка данных импорта.
- `perceptual-cover-check.json`: сравнение 500 изображений между собой
  и со старой библиотекой из 2190 обложек.
- `final-covers.json`: состав отобранных иллюстраций.

Проверка сходства локальная: точные длинные абзацы и сходство наборов
пятисловных фрагментов. Внешний сервис проверки уникальности не использовался.

Публикация выполняется существующим workflow после push в `main` и успешного
деплоя/импорта. Новые статьи получают фактическое время импорта; даты уже
опубликованных материалов сохраняются. Сам коммит без push не обновляет сайт.

Повторная проверка:

```sh
python scripts/news/review_batch.py --batch content/news/batches/2026-10-28-500
python scripts/news/review_existing.py --batch content/news/batches/2026-10-28-500
python scripts/news/validate.py
python -m unittest discover -s scripts/news -p 'test_*.py'
```
