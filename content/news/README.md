# Новости

`plan.json` задаёт темы, `articles/<slug>.json` содержит текст и SEO-поля,
`covers.json` — источники, авторов и лицензии фотографий.
Обложки находятся в `frontend/public/news/<slug>.jpg`.

Проверка: `python scripts/news/validate.py`.
Тесты загрузчика: `python -m unittest discover -s scripts/news -p 'test_*.py'`.
Загрузку через административное API выполняет `scripts/news/seed.py`;
при деплое она запускается существующим GitHub Actions workflow.

Явное поле `"published": false` означает черновик без даты публикации
и уведомления IndexNow. Отсутствие поля сохраняет прежнее поведение.
`--update` применяет статус из JSON; при публикации существующего черновика
назначается текущая дата, а его адрес передаётся в IndexNow.

## Пакет от 21 октября 2026 года

320 материалов по 16 тематическим группам подготовлены к публикации:
семь исходных статей отредактированы, 313 остальных содержательно переписаны.
Каждый текст содержит 7500–8600 знаков после удаления HTML и декодирования
сущностей; заголовки, описания и ключи сформулированы для отдельной темы.
Общие подстановочные блоки прежних черновиков удалены.

Проверены формат всех статей, объём, точные повторы абзацев и метаданных,
внутренние ссылки, источники, размеры обложек 1200×675 и сведения о лицензиях.
Такая проверка не является сертификатом внешнего сервиса уникальности
и не гарантирует поисковые позиции. Нормативные выводы относятся к указанным
условиям; расчётные примеры не представлены как реальные кейсы института.

Новые материалы используют обычную структуру новостей и существующий импорт.
Отдельного публичного каталога пакета или альтернативного хранилища нет.
