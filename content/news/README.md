# Новости

`plan.json` задаёт темы, `articles/<slug>.json` содержит текст и SEO-поля,
`covers.json` — сведения об источниках и лицензиях фотографий.
Обложки находятся в `frontend/public/news/<slug>.jpg`.

Проверка: `python scripts/news/validate.py`.
Загрузку через административное API выполняет `scripts/news/seed.py`;
при деплое она запускается существующим GitHub Actions workflow.

Явное поле `"published": false` в статье означает черновик без даты
публикации и уведомления IndexNow. Отсутствие поля сохраняет прежнее
поведение загрузчика. `--update` также применяет указанный статус.

## Пакет от 21 октября 2026 года

Добавлены 320 материалов по 16 группам, с обложками и SEO-полями.
Все 320 сохранены как черновики: семь текстов написаны отдельно,
313 используют общие редакционные конструкции с подстановками.
Они не соответствуют требованию о полноценных независимых статьях
без повторяющихся блоков и требуют содержательной переработки.
Проверка формата и отсутствия точных совпадений этого не заменяет.
Внутренние ссылки объединяют пакет, поэтому отдельные материалы
тоже не отмечены для автоматической публикации.

Перед публикацией нужно проверить каждый текст, его источники,
применимость требований, соответствие обложки и внутренние ссылки.
После редакционной приёмки публикация выполняется через админку
либо явным изменением статуса статьи в JSON и повторным импортом.
